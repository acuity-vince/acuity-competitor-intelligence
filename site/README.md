# Acuity Broker Intelligence

A hosted, interactive view of the normalized broker registry, packaged as a Next.js application for ChatGPT Sites.

## Refresh data

Copy the latest `outputs/forex-broker-master-registry.csv` to `public/site/data/registry.csv`, commit the source, and publish a new Sites version.

## Local development

Install dependencies and run `npm run dev`, then open the local Next.js URL. The application shell serves the registry interface from `/site/index.html`.
